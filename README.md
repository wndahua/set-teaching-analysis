# 学生评教（SET）影响因素分析

用 R 和 SQL 分析 340 门课程的学生评教数据，回答一个问题：**除了老师本身，还有什么在影响评教分数？**

作者：文锦鸿 ｜ 2026.11

## 数据

- 来源：课程提供的 SET 数据集（某学院 2002–2004 年评教记录）
- 规模：340 行 × 7 列
- 字段：教师职称、性别、学生类别、年份、学期、班级人数、课程评分

## 方法

**SQL（MySQL 5.7）**

- 建库建表、字段类型设定、字符集处理（utf8mb4）
- 分组聚合、交叉表、`CASE WHEN` 分组、多条件筛选

**R**

- 多元线性回归，含分类变量基准组设定
- 非线性检验（二次项、对数变换）与模型比较（AIC / BIC）
- 残差诊断、多重共线性（GVIF）
- 岭回归 / Lasso + 训练集测试集划分
- 200 次随机划分的稳健性检验

## 主要结论

1. **职称不是"越高越好"**：正教授课程比助理教授高 0.261 分（p = 0.002），但副教授与助理教授无显著差异（p = 0.257）。
2. **学生类别影响最大**：研究生课程比 MBA 高 0.278 分（p < 0.001）。
3. **班级人数的影响是假象**：单变量呈负相关，控制学生类别后不显著（−0.0006，p = 0.585）；去掉该变量后反而显著（−0.0021，p = 0.041）。原因是 MBA 课程平均 49.8 人、均分 4.13，研究生课程平均 27.8 人、均分 4.44。
4. **学期效应也是假象**：春季比秋季高 0.243 分，但春季 85 门课全部由正教授承担，控制教师构成后系数降到 0.009。
5. **人数影响是非线性的**：加入平方项显著（F(1,329) = 7.70，p = 0.006），拐点约 64 人，整体呈 U 型。
6. **正则化没有带来实质提升**：200 次随机划分下，OLS / 岭回归 / Lasso 的平均 RMSE 分别为 0.4463 / 0.4455 / 0.4446，差异（约 0.002）远小于划分之间的波动（约 0.03）。

一句话总结：模型 R² 仅 0.17，评教分数主要由模型之外的因素决定。

## 复现

1. **导入数据**：HeidiSQL 打开 `set_import.sql`，按 F9 执行
2. **执行查询**：打开 `analysis.sql`，全选后按 F9
3. **生成报告**：RStudio 打开 `analysis.Rmd`，点 Knit

R 依赖：`tidyverse`、`broom`、`car`、`glmnet`、`patchwork`

## 局限

- 样本仅 340 门课程，部分交叉类别（如 2002 年助理教授）只有 20 门
- 评分为 5 分制且多数集中在高分，存在天花板效应，残差非正态
- 缺少课程难度、学生基础等关键变量，R² 仅 0.17
- 学期与教师构成完全绑定，无法分离季节的独立影响
- 以上均为相关关系，不构成因果结论
